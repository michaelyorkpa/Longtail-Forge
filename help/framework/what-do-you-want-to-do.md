# What Do You Want to Do?

Start with the result you want. Each route uses current shipped actions and keeps the work attached to its active workspace and readable context.

## Track time against a client or project

1. Open **Actions → Time Keeping → Time Tracker** for a timer, or **Time Entries** for a saved entry.
2. Choose the Client first when the workspace uses business clients, then choose the Project.
3. Add the work description and billable state, then start the timer or save the entry.
4. Use **Time Entries** to review or correct saved work when your role allows it.

See [Time Tracking Action Reference](/help.html?article=time-tracking-actions), [Timers and Saved Duration](/help.html?article=time-tracking-timers), and [Time Entries and Corrections](/help.html?article=time-tracking-entries-corrections).

## Capture something without losing focus

1. Open **Quick Actions** from the app shell.
2. Choose **Task**, **Note**, or **List** for the kind of context you need to preserve.
3. Save the minimum useful title and linked context.
4. Return focus to the control or work item you were using.

Use **Timer** instead when the capture is elapsed effort. See the [Action Catalog](/help.html?article=action-catalog) and the active module’s action reference.

## Hand a project to another user

1. Open **Settings → Admin → Users** and confirm the person is an active member of the workspace.
2. Add or edit the person’s role assignment at the correct workspace, client, or project scope.
3. Use **Permissions** only for an intentional operation override.
4. Open **Projects**, edit the project, and update any offered assignments or task defaults.
5. Review the project’s open tasks and assign the concrete next actions to the new owner.

Role scope controls what the user can see; changing a label or task assignment does not grant project access. See [Users, Roles, and Permissions](/help.html?article=users-roles-and-permissions), [Clients and Projects](/help.html?article=clients-and-projects), and [Tasks Action Reference](/help.html?article=tasks-actions).

## Resume work after an interruption

1. Open **Workbench**.
2. Start with **Pick up where I left off**, or choose **Start with what’s due**, **Work this week**, **Review blocked work**, or **Focus on a project**.
3. Review the recommended action and its Inspector context.
4. Use **Resume task**, **Open**, or the module action that matches the selected record.

See [Resuming Task Work](/help.html?article=tasks-resume-context), [Resuming List Work](/help.html?article=lists-resume-context), and [Active Work](/help.html?article=notes-active-work) for module-specific recovery cues.

## Capture and complete a task

1. Use Quick Actions **Task**, Tasks **Add Task**, or Workbench **Add Task**.
2. Record the outcome, next action, assignees, due context, and project when they matter.
3. Add checklist items or recurrence only when the task needs them.
4. Use **Start Timer**, **Block**, **Resume**, **Complete**, **Reopen**, **Archive**, or **Restore** as its state changes.

See [Tasks Action Reference](/help.html?article=tasks-actions) and [Tasks Basics](/help.html?article=tasks-basics).

## Turn a repeated checklist into reusable work

1. Open **Lists** and choose **Create List**.
2. Add the concrete items and their quantities, needed dates, assignees, and status.
3. Choose **Mark Reusable** when the completed structure should become a future starting point.
4. Choose **Duplicate** to create another working copy without changing the reusable source.

See [Lists Action Reference](/help.html?article=lists-actions) and [Reusable Lists and Suggestions](/help.html?article=lists-reusable).

## Attach and recover source material

1. Open the task, note, list, client, project, or other record that owns the material.
2. Use its **Files** or attachment control to upload.
3. Open **Actions → Files** to find visible attachments across the workspace.
4. Use **Preview** when supported or **Download** for download-only formats.
5. Click a row for **Edit File Context** when Target, Project, or Business Client context needs correction.

See [Files and Attachments](/help.html?article=files-and-attachments) and the [Action Catalog](/help.html?article=action-catalog).

## Find something you remember only partly

1. Open app-shell **Search** or Quick Actions **Search**.
2. Enter the title, body wording, tag, context, or Help phrase you remember.
3. Narrow by source when needed.
4. Open the result to route through its registered action.

Search respects current workspace, module, lifecycle, and permissions. See [Search](/help.html?article=search).

## Configure a workspace or module

1. Open **Settings**.
2. Choose **User** for personal preferences, or **Admin** for workspace-owned controls.
3. Choose **Modules** for enablement and module-specific settings.
4. Save only the section you intended to change.

See [Administration and Settings](/help.html?article=administration-and-settings) for the end-to-end route map.

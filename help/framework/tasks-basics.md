Tasks is a first-party Longtail Forge module. Tasks can be scoped to a workspace, client, or project depending on the active workspace and available modules. A task has a title, status, priority, assignees, optional due date and time, and optional client or project context.

The Tasks page supports single-task editing and selected-task bulk changes. Bulk edit can update status, priority, assignees, due date, due time, and tags. Due date and due time can be set or cleared separately; clearing a due date also clears the due time because a task cannot keep a due time without a date. Blocking one or several tasks requires a Blocked Reason. When selected tasks have mixed due dates, due times, or tags, the page shows an in-app confirmation before applying the change. The tag filter accepts typed searches and keyboard selection from suggestions.

The Add/Edit Task dialog keeps the title and a compact metadata ribbon near the top. Task Details holds parent task, status, priority, client, project, due date, and due time. New child tasks can inherit the parent's schedule, priority, and empty Client/Project context; completed and archived tasks are not offered as new parents. Task rows nest visible children under their parent and provide a clickable `Child of:` chip. Next Action and Resume Note sit together so the next step and handoff context are easy to compare. Blocked Reason appears only while the task is blocked and is required in that state. Checklist and Assignees start collapsed unless they already contain checklist items or selected assignees. Enter adds or saves the focused checklist item without closing the task.

The task heading bell follows or unfollows notifications for the task; a red bell means notifications are enabled for that task. Footer icons open task tags and files inside the task workflow and copy the task link. In create mode, Save records the task and keeps the dialog open as an edit dialog, while Save & Close records it and exits; Cancel exits without another save. Those icon buttons keep accessible labels and hover titles even when the visible button text is hidden.

Task permissions control who can view, create, edit, assign, complete, archive, restore, or attach files to tasks. Users may see only the tasks allowed by their role scope.

When Tasks and Time Tracking are both enabled, eligible open tasks can start task timers. Task timers finalize into normal time entries with task context. Completed tasks can show a compact `TTC:` duration chip after completion metadata is saved.

When a recurring task is completed, Tasks shows `Next scheduled` while the next occurrence is created in the background. Once it is ready, `Open next task` goes directly to that occurrence. If the series has no future date, Tasks says that the recurring series ended. Future checklist steps start unchecked, and a Blocked Reason entered on one occurrence does not carry into the recurrence template or later occurrences.

# Dashboard and Workbench

Dashboard and Workbench answer different questions. Dashboard answers “What is happening in this workspace?” Workbench answers “What can I start or resume now?”

## Dashboard is the overview

Use Dashboard to scan workspace pulse, setup warnings, due or blocked pressure, calendar context, active timers, recent time, and other summaries contributed by active modules. Its cards are compact and permission-shaped. They link to the owning workflow instead of turning Dashboard into a second editor.

Dashboard is useful when you are orienting yourself, reviewing the workspace, or deciding which area needs attention. A card can open Workbench, Notifications, Calendar, Tasks, Settings, or another module surface. The destination owns the detailed behavior.

Dashboard does not replace Tasks, Time Entries, Notes, Lists, Files, or Reporting. If a module is disabled or you cannot read its data, its contribution does not appear.

## Workbench is the live work surface

Use Workbench when you want one useful next action, an active timer, a saved handoff, or related context without rebuilding the whole work thread. Focus Selection asks what kind of work you want to surface. The recommendation card gives a bounded set of candidates; Previous and Next move through that set.

Opening a Task recommendation enters Task Focus. Task Focus keeps the task’s actions, timer, checklist, continuity fields, and Inspector context together. Other recommendation types open through their registered module action. The Inspector is supporting context, not a second copy of the owning module’s editor.

Running and paused timers remain prominent because active effort is already in motion. Workbench can also show module-owned lists beneath the recommendation area when their modules contribute them.

## Choosing the surface

| If you need to… | Start in… | Why |
| --- | --- | --- |
| Scan the workspace | Dashboard | It summarizes several areas without asking you to edit them there. |
| Continue interrupted work | Workbench | It prioritizes resume state, live timers, and current work context. |
| Choose from due or blocked work | Workbench | Focus choices narrow and order startable candidates. |
| Review one module in depth | The module page | The module owns its complete list, filters, editor, and lifecycle actions. |
| Find something you only partly remember | Search | Search is the cross-workspace recovery route for indexed, readable records. |

Use [Workbench Focus and Recovery](/help.html?article=workbench-focus-and-recovery) for the current focus choices and handoff behavior.

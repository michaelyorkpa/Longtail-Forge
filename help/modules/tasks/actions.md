# Tasks Action Reference

Tasks actions appear only when the Tasks module is active and your current workspace permissions allow them.

## Task list

| Action | Intent | Location |
| --- | --- | --- |
| Add Task | Create a task and preserve its outcome and context. | Tasks header; Workbench recovery; Quick Actions **Task**. |
| Open / Edit Task | Review or change the selected task. | Task title, Search result, Workbench, or task row. |
| Assign | Update the task’s offered assignees. | Task row workflow actions. |
| Due Date / Due Time | Add or change scheduling context. | Task row workflow actions. |
| Recurrence | Create, edit, or remove the recurrence rule. | Task row or task editor. |
| Start Timer / Pause Timer / Resume Timer | Control elapsed effort attached to the task. | Task row, task editor, or Workbench. |
| Complete / Reopen | Finish the task or return it to active work. | Task lifecycle actions. |
| Block / Resume | Record a blocked reason or return the task to startable work. | Task lifecycle actions and Workbench. |
| Archive / Restore | Remove a task from current work or recover it with history intact. | Task lifecycle actions. |

## Task editor

Use **Save task** to save and remain in the editor, **Save & Close** to save and return focus, or **Cancel** to leave without saving the current changes. **Complete task**, **Open in Workbench**, **Copy Link**, **Tags**, and **Files** are editor utility actions.

The editor also offers:

- **Add checklist item** and each item’s Done control.
- **Save Recurrence** or cancel the recurrence dialog.
- Timer **Start**, **Pause**, **Save Time**, and **Reset**.
- Follow or unfollow task notifications.
- Child-task and parent-task links, including **Open next task** after recurrence generates continuity.

## Bulk Actions

Select visible tasks, choose the offered bulk change, and use **Apply to _n_**. Available changes depend on state and permission and can include assignment, due context, lifecycle changes such as **Archive selected** or **Restore selected**, and other explicitly offered task fields. Bulk actions never expand visibility beyond the selected readable tasks.

## Dashboard, Calendar, and Workbench

Dashboard Tasks cards route to Tasks, Calendar, Workbench, or the selected task. Calendar is a read-only due-date and reminder view that opens the task for editing. Workbench provides **Resume task**, **Edit task**, **Complete task**, **Block task**, checklist progress, and task-timer controls.

See **Resuming Task Work** for the recovery fields that make those actions useful.

Lists are operational execution aids. Use them for grocery runs, household shopping, trip packing, project supplies, procurement, parts, bills of materials, and repeatable checklists.

A list has a title, type, status, optional business client/project context, items, item progress, source context, linked records, tags, files, and safe recovery context. Lists are not notes, tasks, bookmarks, inventory, purchasing, accounting, vendor management, manufacturing, or ERP records.

Use the filter button at the bottom-left of the Lists page to open filters and the List Selector. Choosing a list collapses the selector and keeps the selected list on the full-width main page.

The selected list starts with a collapsible List Details box. It shows the list description and any linked records as read-only context, then the Next, Source, items, and Costs areas continue below it.

To add or remove linked records, open Create List or Edit List and use the Linked Records picker. Choose a target type, search, select a readable record, and choose Use Target. Tasks, notes, and projects are available when you can read them; clients are available in Business workspaces. New-list links are saved when the list is created, while changes to an existing list are applied from the editor.

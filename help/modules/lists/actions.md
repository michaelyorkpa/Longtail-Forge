# Lists Action Reference

Lists actions appear only when Lists is active and your current permissions allow them.

## List actions

| Action | Intent | Location |
| --- | --- | --- |
| Create List | Start an operational shopping, procurement, packing, supplies, parts, or checklist workflow. | Lists header; Quick Actions **List**. |
| Edit | Change the selected list’s title, type, context, or description. | Selected list action strip. |
| Duplicate | Create a new working copy. | Selected list action strip. |
| Complete / Reopen | Mark the workflow complete or return it to active work. | Selected list action strip. |
| Finalize | Lock in the completed list state when permitted. | Selected list action strip. |
| Mark Reusable / Unmark Reusable | Add or remove the list as a repeatable starting point. | Selected list action strip. |
| Archive / Restore | Move the list out of or back into current work. | Selected list action strip. |
| Delete | Move the list into its supported deleted lifecycle after confirmation. | Selected list action strip. |

Use **Save List** to save the editor or **Cancel** to leave the current values unchanged.

## Item actions

| Action | Intent | Location |
| --- | --- | --- |
| Add Item | Add a concrete item with quantity, needed date, assignee, status, cost, vendor, URL, tracking, and notes when useful. | Selected list Items form. |
| Done | Check or uncheck item progress. | Item row. |
| Edit | Change the item. | Item row action. |
| Up / Down | Reorder the item within the list. | Item row action. |
| Delete | Remove the item after the offered confirmation. | Item row action. |
| Save as reusable item | Add the item to catalog-backed suggestions when saving. | Item form. |

## Links, files, tags, and recovery

Use the offered linked-record controls to connect permission-visible tasks, notes, projects, or business clients. Use **Files** for attachments and **Tags** for classification. These actions do not grant access to the linked record.

The selector and slide-out filters narrow status, type, reusable state, client, project, assignee, needed date, archived state, and sort order. Selecting a list reveals its action strip, progress, next-action context, source, costs, and items. Search and Workbench-related context can route back to the registered **Edit** action.

See **List Items and Progress**, **Reusable Lists and Suggestions**, **Linked Records**, and **Resuming List Work**.

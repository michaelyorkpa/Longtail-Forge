Lists can link to supported records so execution context stays near the work. Initial linked targets are tasks, notes, projects, and business-workspace clients.

Add or remove links from the Create/Edit List window. The Linked Records picker lets you choose the target type, search the records you can use, select one result, and choose Use Target. The List Details box on the Lists page is read-only.

Linked records make a list easier to resume, but the link does not grant access to either side. If a user cannot read a linked target, Lists shows only safe unavailable context and does not expose hidden labels or URLs. List items remain list items; linked tasks stay tasks, and linked notes stay reference or working context.

# Notes Action Reference

Notes actions appear only when Notes is active and your current permissions allow them.

## Notes page

| Action | Intent | Location |
| --- | --- | --- |
| Create Note | Capture working context in the selected Library and collection. | Notes header; Quick Actions **Note**. |
| View Note | Open a readable note without entering edit mode. | Notes selector, Search, or Workbench related context. |
| Edit | Change the selected note. | Note action strip or registered Notes action. |
| Archive / Restore | Move a note out of or back into its original Library bucket. | Note action strip. |
| Add Link / Remove | Connect or disconnect a permission-visible record. | Selected note Linked Context. |
| Create / edit collection | Organize notes in a single Library bucket. | Notes collection controls. |

## Editor and supporting context

Use **Save Note** to save and keep editing, **Save & Close** to save and return focus, or **Cancel** to leave without saving the current changes. The editor exposes permitted Library, Collection, Note Kind, Visibility, and Security choices.

Use the note’s **Tags** and **Files** controls to classify it or attach source material. Use revision actions to review meaningful history and restore an earlier revision when your permission allows it. Secure-note actions never expose encrypted payloads or crypto metadata.

## Bulk changes

Select visible notes and open the bulk editor to change an offered Library, Collection, Note Kind, Visibility, or direct-tag operation. Choose **Apply Changes** to update the selected notes or **Cancel** to leave them unchanged. Bulk changes preserve existing access checks and do not reveal hidden notes or linked targets.

## Recovery

Open Notes from Search, Workbench related context, a linked record, or the Library selector. Use Active Work for current context, Ongoing Areas for durable responsibilities, Reference Library for retained material, and Archive for completed context.

See **Using Notes**, **Note Linking**, **Note Revisions**, and **Notes, Files, and Search** for the behavior behind these actions.

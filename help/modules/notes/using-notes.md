Notes are internal working records. A note can stand alone in the Notes Library or link to a client, project, task, ticket, or user when that context helps explain the work.

Each note has a title, Markdown body, Library bucket, status, visibility, owner, optional linked context, tags, files, and revision history. Notes follow the same module-state and permission checks as the rest of Longtail Forge, so a Library bucket, collection, tag, or linked record never grants access by itself.

To update several notes at once, select their checkboxes in Notes List and open Bulk Edit. You can change Library, Collection, Note Kind, and Visibility while leaving any other field unchanged. Choosing a collection also moves the notes into that collection's Library. Changing Library without choosing a collection moves the selected notes to Uncategorized. Archived notes must be restored before editing, and every selected note still goes through its normal access checks.

When creating a note, Save keeps the dialog open and converts it to Edit Note after the record is persisted. Saved-note tools such as Copy Link, notification following, Tags, and Files then become available without reopening the note. Choose Save & Close when you want to commit the note and leave the dialog immediately.

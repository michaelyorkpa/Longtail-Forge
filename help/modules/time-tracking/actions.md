# Time Tracking Action Reference

Time Tracking actions appear only when the module and workspace capability are available and your permissions allow them.

## Timers

| Action | Intent | Location |
| --- | --- | --- |
| Timer / Create Timer | Start a manual timer with its current context. | Quick Actions **Timer**, Time Tracker, or Workbench. |
| Start | Begin or resume elapsed time. | Time Tracker and Workbench active timer. |
| Pause | Stop accumulating time without saving the entry. | Time Tracker and Workbench active timer. |
| Save & End / Save Time / Finalize | Turn elapsed time into a saved time entry. | Active timer, task timer, or Workbench. |
| Discard / Reset | Remove the unsaved timer after confirmation where required. | Active timer or task timer. |

Task-owned timers also expose **Start Timer**, **Pause Timer**, and **Save Time** from the task row or editor.

## Saved entries

| Action | Intent | Location |
| --- | --- | --- |
| Add Time Entry | Record a completed duration without running a timer. | Actions → Time Keeping → Time Entries. |
| Edit Time Entry | Correct an allowed saved entry. | Time Entries row or Search result. |
| Save / Save & Close / Cancel | Save the entry and choose whether to remain in the editor, or leave unchanged. | Time Entry dialog. |
| Attach / remove Files | Preserve source material with the entry. | Time Entry dialog when Files access is available. |
| Filter, sort, and page | Narrow the saved-entry listing by offered date, context, owner, billing, or status fields. | Time Entries. |

Correction permissions determine whether you can edit your own entry, any entry, or only review it.

## Dashboard, Workbench, and Reporting

**Active Timers** and **Recent Time** Dashboard cards open the relevant timer or saved-entry context. Workbench active timers provide **Start**, **Pause**, **Save & End**, and **Discard**.

Under Reporting, **Project Time & Billing** accepts the offered billing period or custom range, reporting scope, projects, tags, and descendant option. Run the report to review saved duration and billable totals, then use an offered export action when needed.

See **Timers and Saved Duration** and **Time Entries and Corrections** for lifecycle and correction rules.

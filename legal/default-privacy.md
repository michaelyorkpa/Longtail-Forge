# Operator Privacy Notice Template

This is a neutral template for a self-hosted Longtail Forge installation. It is not a privacy notice issued by Raymond Tec, and it must not be presented as one.

The person or organization operating this installation is responsible for determining why and how personal data is processed. That operator must replace this template with an accurate privacy notice before offering the service to users.

## Operator responsibility

Contact the operator of this installation for information about the data it collects, its purposes and legal bases, retention, sharing, security practices, user rights, and contact details.

Longtail Forge software does not make Raymond Tec the data controller for an independently operated installation.
